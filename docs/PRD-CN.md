# KeyFlow Studio Lite 产品需求文档（PRD）

- 产品名称：KeyFlow Studio Lite
- 当前基线：1.0.0
- 平台：Windows 10/11 x64
- UI：WinForms
- Runtime：.NET 10 + Lua 5.4（NLua/KeraLua）
- 产品原则：本地优先、轻量、可预测、可回滚，不依赖云端服务。

## 1. 产品定位

KeyFlow Studio Lite 是面向 Windows 桌面用户的键盘/鼠标自动化工具。核心路径是：创建脚本、录制物理操作、编辑 Lua、设置循环与间隔、播放/暂停/停止、查看运行日志。它是独立实现，不使用第三方闭源代码或未经授权素材。

Lite 不以覆盖所有高级自动化场景为目标。优先保证基础键鼠自动化长期稳定、输入释放可靠、旧脚本可持续运行。

## 2. 目标用户与场景

- 需要重复执行桌面点击、键盘输入和滚轮操作的 Windows 用户。
- 希望通过录制快速生成脚本，再手工调整 Lua 的用户。
- 需要循环任务、暂停/恢复和紧急停止的用户。

典型任务：重复点击、表单操作、简单键盘组合、固定步骤回放、文本输入和带间隔的重复执行。

## 3. 核心用户流程

1. 启动应用，使用悬浮窗或主界面打开/新建脚本。
2. 点击开始录制；可切换只记录点击模式；需要时暂停和继续。
3. 结束录制，检查并编辑生成的 Lua 脚本，保存。
4. 配置执行次数与轮间隔；0 次表示无限循环。
5. 播放脚本；可暂停/继续或停止。停止、异常和退出路径必须尽最大努力释放所有按下的输入。
6. 从日志确认执行状态和错误信息。

## 4. 1.0.0 已交付需求

- 本地脚本管理：新建、打开、保存、重命名、复制、删除。
- Lua 5.4 执行：脚本在独立 Worker 中运行，UI 保持响应。
- 鼠标：移动、左/右/中键点击、Down/Up、滚轮。
- 键盘：KeyPress、KeyDown/KeyUp、Hotkey、Unicode TypeText。
- 时间：Delay、RandomDelay、点击/按键保持时长。
- 录制：鼠标与键盘全局低级 Hook、暂停/续录、只录点击、移动事件降噪。
- 播放：循环次数、轮间隔、暂停/继续/停止、F10/F11/F12。
- UI：主窗口、独立悬浮窗、托盘、置顶、坐标显示和状态同步。
- 配置：本地设置持久化。

详见 `docs/FEATURE-MATRIX-CN.md` 和 `docs/LUA-API-CN.md`。

## 5. 非功能需求

- **稳定性：** 不允许未配对 Down/Up 长时间遗留；异常和取消路径必须释放输入。
- **响应性：** Lua 不在 UI 线程运行；UI 不因长脚本卡死。
- **可恢复性：** 脚本保存尽量使用临时文件/备份策略；设置损坏时提供默认值。
- **兼容性：** 保留旧版脚本目录和配置路径；已发布 Lua 函数语义不得静默变化。
- **可观测性：** 运行状态和错误必须能在日志中理解。
- **隐私：** 脚本与运行数据默认本地存储，不上传用户内容。

## 6. 明确不属于 Lite 1.0.0 的范围

- 图像资源、找图/找色、OCR。
- 高级 IDE、语法补全、断点调试、可视化动作列表。
- 脚本参数设计器、复杂自定义 UI、小精灵打包。
- 插件系统、受控网络/文件 API、定时任务、多实例管理。
- 云同步、账号系统、遥测和远程执行。

若未来要增加上述能力，必须先更新产品范围和路线图，不得默默把 Lite 扩成完整专业版。

## 7. 完成定义

功能实现同时满足：源码与文档一致、自动化测试通过、Windows x64 发布构建通过、关键失败路径有测试、实机未测项保持 NOT RUN、版本与 Release 资产可复现。
