# KeyFlow Studio Lite 路线图

当前稳定版本：**1.1.1**（2026-11-20 已正式发布）。固定点击节奏与第二轮悬浮窗布局已交付；Windows Actions 全部通过，真实 Windows 桌面验收仍待完成。

路线图以“先稳定基础键鼠自动化，再决定是否扩展”为原则。未经用户明确批准，不将专业版功能并入 Lite。

| 阶段 | 状态 | 交付目标 |
|---|---|---|
| M0 — Lite 1.0.0 基线迁移 | DONE | 将原稳定版源码、文档与 CI 独立迁入本仓库，并重新发布本仓库 Release |
| M1 — 基线核验与稳定性补强 | NEXT | 按验收清单核对实际行为；补足录制、暂停、停止、Worker 和输入释放测试 |
| M2 — Windows 实机验收 | TODO | Windows 10/11、DPI/多屏、托盘、权限、真实键鼠与长时运行 |
| M3 — 小范围 UX 与可维护性改进 | DONE | v1.1.0 完成固定点击节奏；v1.1.1 根据实机截图重整悬浮窗层级与参数分区；后续再评估 MainForm 拆分 |
| M4 — Lite 维护发布 | IN PROGRESS | 按 SemVer 发布 1.1.x 维护版本并持续维护下载/校验/回滚 |

## 1.1.1 悬浮窗调整与验证

- 新版独立悬浮窗目标尺寸为 600 × 190 px，按标题/状态、动作、运行参数和点击节奏分区。
- 主界面与既有脚本操作逻辑未重做；当前只对独立悬浮窗作视觉与排版调整。
- Release v1.1.1 与 SHA256 文件已发布；Windows Actions build/test/package/release 全部 PASS。
- 实机 DPI、混合多显示器、拖动、负坐标和无截断验收仍为 NOT RUN。

## 1.1.0 已交付与验证

- 默认关闭固定点击间隔，保持旧脚本录制节奏不变。
- 启用后，以连续点击之间的间隔为总预算；点击后等待固定保留，剩余预算与悬停等待合并。
- 只在“只录点击坐标”模式改变输出；完整鼠标轨迹录制不受影响。
- 录制预览与最终 Lua 生成共享同一份会话参数。
- Release v1.1.0 与 SHA256 校验文件已发布；Windows Actions 全部通过。
- 真实 Windows 悬浮窗/DPI/拖动/目标软件菜单与长时录制验收继续列为 NOT RUN，需实机完成。

## 1.0.1 已交付项

- 解决方案、项目目录、项目名、命名空间、程序集、可执行文件和 Worker IPC 标识统一使用 KeyFlow。
- 首次启动将旧版数据中尚不存在于新数据目录的文件非破坏性复制，保留原目录。
- 悬浮窗固定宽度由 640 px 调整为 500 px，重新分配头部、动作按钮、循环设置和坐标的空间。

## M1 进入条件

M0 的新仓库 CI 和 `v1.0.0` Release 完成后开始。M1 首先做基线代码审查和测试覆盖差距分析，不直接新增高阶功能。

## M1 优先检查

1. GlobalRecorder 暂停/续录、Hook 部分安装失败、输入 Down/Up 配对和事件上限。
2. PlaybackRunner Stop、Worker 异常退出、命名管道断开和 ReleaseAll 的所有分支。
3. 托盘关闭/隐藏/退出、悬浮窗/主窗口互相状态同步。
4. settings.json 损坏、并发写入和脚本保存失败恢复。
5. SendInput 权限不足、目标程序管理员权限差异、DPI 与虚拟桌面负坐标。

## 版本规则

- 仅缺陷修复：1.0.1、1.0.2……
- 向后兼容的新能力：1.1.0……
- 破坏性变更：2.0.0。
- 预发布按 SemVer：1.1.0-preview.1。
- 不创建含糊的 FIX tag，不复用正式版本号。
